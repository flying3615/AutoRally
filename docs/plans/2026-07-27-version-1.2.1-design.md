# Version 1.2.1 Design

## Goal

Release the next patch version as `1.2.1` with consistent package and Electron
application metadata.

## Version Source

Electron Builder reads the application version from the root `package.json`.
The root package record in `package-lock.json` must match it so installs and
release metadata remain consistent.

## Approach

Run `npm version 1.2.1 --no-git-tag-version` in an isolated worktree. This
updates the root version fields in both manifests without creating a Git tag or
changing dependency versions.

## Verification

Confirm both manifests report `1.2.1`, inspect the focused diff, and run the
existing TypeScript type check. No installer artifacts are generated.
